# Win11 站点样式规范（STYLE-GUIDE）

> **适用对象**：负责开发 Web 页面的 AI Agent / 开发者。
> **目标**：让页面严格呈现 Windows 11 / Fluent 视觉风格，做到零歧义、可执行、可自校验。
> **配套文件**：`tokens.json`（设计变量数据源）、`ui-preview.html`（组件参考实现）。
> **程度词**：本文使用「必须 / 禁止 / 应 / 推荐 / 可选」——必须/禁止为硬性约束，违反即不合格。

---

## 0. 总则

一句话定位：**Win11 风格 = 简洁、通透、圆润、留白充足、层次清晰**。核心是「内容优先、克制装饰」。

- **必须**使用 `tokens.json` 中的值，禁止引入 tokens 之外的散落颜色/字号。
- **必须**支持浅色 / 深色两套主题，且通过统一机制切换（见第 5 节）。
- **禁止**使用浓重的实心色块、夸张渐变、厚重边框、拟物阴影。
- 页面整体应呈现「浅灰底 + 白色卡片 + 轻阴影 + 圆角」的层次。

---

## 1. 设计变量（Design Tokens）

- 全部设计变量定义于 `tokens.json`，**必须**以其为准。
- 前端推荐做法：将 `tokens.json` 转成 CSS 自定义属性（`--color-accent` 等），组件一律引用变量，**禁止**硬编码十六进制。
- 引用示例（把 token 名与 CSS 变量一一对应，见 `ui-preview.html` 的实现方式）。

核心速查表（浅色主题）：

| 用途 | Token | 值 |
|---|---|---|
| 页面背景 | `color.light.background` | `#F3F3F3` |
| 卡片/面板 | `color.light.surface` | `#FFFFFF` |
| 主文字 | `color.light.textPrimary` | `#1B1B1B` |
| 次要文字 | `color.light.textSecondary` | `#5F5F5F` |
| 强调色（主按钮/链接） | `color.light.accent` | `#0067C0` |
| 边框 | `color.light.border` | `#D6D6D6` |
| 成功/警告/错误 | `success` / `warning` / `error` | `#0F7B0F` / `#9D5D00` / `#C42B1C` |

---

## 2. 布局与栅格

- 页面**最大内容宽度 1280px**，两侧留白，居中。
- 间距**必须**使用 4px 基准体系：`4 / 8 / 12 / 16 / 24 / 32 / 48`，禁止出现 5px、7px 等非基准值。
- 卡片内边距推荐 `16px`（`spacing.lg`）；卡片间距推荐 `12–16px`。
- 断点（响应式）：
  - `≥1280px`：桌面多列
  - `1024–1279px`：降为更窄布局
  - `768–1023px`：两列并行为一列
  - `<768px`：单列，控件触控友好（高度 `40px`）
- 网格列数：桌面 `12` 列；卡片/表单常用 `6 / 4 / 3` 分栏。

---

## 3. 排版

- 字体族**必须**为 `"Segoe UI Variable Text", "Segoe UI", system-ui, sans-serif`。
- 字号阶梯（`tokens.json` → `font.size`）：

| 层级 | 值 | 字重 | 用途 |
|---|---|---|---|
| Caption | 12px | 400 | 辅助说明、时间戳 |
| Body | 14px | 400 | 正文（默认） |
| Body Large | 16px | 400 | 强调正文、列表主文本 |
| Subtitle | 20px | 600 | 区块标题、卡片标题 |
| Title | 24px | 600 | 页面主标题 |
| Display | 32px | 600 | 首屏大标题 |

- 行高：正文 `1.5`，标题 `1.25`。
- 标题层级**必须**语义化（h1→h6），禁止仅用字号模拟标题层级。

---

## 4. 色彩

- 强调色 `accent` **仅**用于：主按钮、选中态、链接、聚焦环、关键图标。
- 文字三阶：`textPrimary`（正文）/ `textSecondary`（次要说明）/ `textTertiary`（占位、禁用）。
- 语义色使用：
  - 成功 → `success`；警告 → `warning`；错误 → `error`；信息 → `info`。
  - 错误类操作（删除、危险按钮）**必须**用 `error` 色，禁止用 `accent`。
- 文本与背景对比度**必须**满足 WCAG AA：正文 ≥ 4.5:1，大号文字 ≥ 3:1。
- **禁止**使用「加粗大红色」式的纯强调表达错误，语义色配图标更清晰。

### 4.1 主题色卡（Color Palette）

- 以 `accent` 为主色衍生 **10 阶色卡**（`palette.accent-50` … `palette.accent-900`），定义于 `tokens.json` 的 `palette` 对象，预览见 `ui-preview.html` 顶部「主题色卡」区。
- **色卡语义**（Material 风格 50→900）：
  - `50 / 100 / 200`：极浅背景、hover 底色、选中底色、图表低层。
  - `300 / 400 / 500`：图表主序列、图标色、次级强调。
  - `600 / 700`：主强调；**700 = 主色 accent**（按钮/链接/聚焦）。
  - `800 / 900`：深色强调、hover/pressed 加深、页脚/标题强调。
- **使用规则**：
  - 图表、多序列可视化**必须**优先用色卡阶区分（50→900 由浅到深），避免自造相近色。
  - 背景层次用浅阶（50–200），文字/图标强调用中深阶（500–900）。
  - 深色主题用深色版色卡（基于 `#60CDFF` 衍生），值见 `ui-preview.html` 的 `[data-theme="dark"]` 变量。

## 5. 主题（浅色/深色）

- 页面**必须**支持 `light` / `dark` 两套主题，通过根元素 `data-theme` 属性切换。
- 切换机制：在 `<html>` 或根容器上设置 `data-theme="light|dark"`，CSS 用 `[data-theme="dark"] { ... }` 覆盖变量。
- 深色主题背景 `#202020`、卡片 `#2B2B2B`、主文字 `#FFFFFF`、强调色 `#60CDFF`。
- 提供切换入口（如右上角按钮），且**默认跟随系统**（`prefers-color-scheme`），可选手动覆盖。
- 图标、图片需在两种主题下均清晰可辨（必要时提供主题变体）。

## 6. 组件规范

每个组件给出：结构、尺寸、状态。参考实现见 `ui-preview.html`。

### 6.1 按钮
- 高度 `32px`（默认）/ `40px`（大），圆角 `4px`，左右内边距 `12px`。
- 类型：
  - **主按钮**：`accent` 背景 + `textOnAccent` 文字。
  - **次按钮**：`surface` 背景 + `border` 边框 + `textPrimary` 文字。
  - **文字按钮**：无背景无边框，仅文字（hover 有浅底）。
  - **危险按钮**：`error` 背景或 `error` 文字。
- 状态（**必须全部实现**）：`hover`（背景变 `accentHover`）、`active/pressed`（`accentPressed`）、`disabled`（`textTertiary` + 降低不透明度）、`focus`（`focusRing` 聚焦环）。
- 聚焦环：`2px` 的 `accent` 描边，所有可交互元素必须可见。

### 6.2 输入控件（输入框/下拉/文本域）
- 高度 `32px`，圆角 `4px`，边框 `1px` `border`，内边距 `12px`。
- 状态：focus 时边框变 `accent`；disabled 用 `textTertiary`；必填/错误态用 `error` 边框 + 错误提示文案。

### 6.3 选择控件（复选框/单选/开关）
- 复选框、单选：`16px` 尺寸；选中态填充 `accent`；focus 有聚焦环。
- 开关（Switch）：轨道 `40×20px`、圆角 `pill`；开启轨道 `accent`、滑块 `textOnAccent`。

### 6.4 卡片
- 背景 `surface`、圆角 `8px`、边框 `1px` `border`、阴影 `card`（浅色 `0 1px 3px rgba(0,0,0,.08)`）。
- 内边距 `16px`；可悬停卡片 hover 时加 `overlay` 阴影。

### 6.5 表格
- 表头：`surfaceSubtle` 背景、`textSecondary`、字重 `600`。
- 行分隔用 `border` 底线（`1px`）；行 hover 用 `surfaceHover`。
- 单元格内边距 `12px`，字号 `14px`。

### 6.6 标签 / 徽章
- 圆角 `4px`，内边距 `4px 8px`，字号 `12px`。
- 用语义色区分（成功/信息/警告/错误），浅色底 + 深色文字，或半透明底。

### 6.7 导航 / 侧栏
- 侧栏：宽 `240px`，背景 `surface` 或 `background`。
- 菜单项：高 `36px`、圆角 `4px`；hover `surfaceHover`；选中项 `selection` 背景（浅色 `#CCE4F7`）。
- 顶部栏：高 `48px`，浅色下与背景同色，深色下略深于背景。

### 6.8 弹窗 / 提示
- 弹窗：`overlay` 阴影、圆角 `8px`、背景 `surface`；遮罩半透明黑 `rgba(0,0,0,0.4)`。
- Toast 提示：圆角 `4px`，出现在角落，可自动消失。

### 6.9 进度条 / 滑块
- 进度条：轨道 `surfaceSubtle`、圆角 `pill`；填充 `accent`。
- 滑块：轨道同上；滑杆（thumb）`accent` 圆点。

---

## 7. 交互与动效

- 时长：hover 反馈 `100ms`；面板显隐 `200ms`。
- 缓动**必须**为 `cubic-bezier(0.1, 0.9, 0.2, 1)`（Fluent 标准）。
- 所有 hover/focus/active 状态变化应平滑过渡（transition），但**禁止**花哨的缩放、旋转、弹跳动画。
- 尊重系统「减少动态效果」：`@media (prefers-reduced-motion: reduce)` 下关闭非必要动画。

---

## 8. 响应式规则

- 断点见第 2 节。
- 移动端：卡片单列、按钮/输入高度升至 `40px`、侧栏收起为抽屉或顶部 Tab。
- **必须**从移动端到桌面逐级验证，禁止出现横向滚动（表格除外可横向滚动）。

---

## 9. 无障碍

- 所有可交互元素**必须**可键盘操作，focus 可见。
- 表单控件**必须**关联 `<label>`。
- 图标按钮**必须**提供 `aria-label`。
- 对比度满足 AA（见第 4 节）。
- 图片加 `alt`；装饰性图片用 `alt=""`。

---

## 10. 交付自检清单（Agent 交付前逐项核对）

- [ ] 无硬编码颜色/字号，全部引用 `tokens.json` 对应变量。
- [ ] 浅色、深色两套主题均可正常切换，无文字/对比度问题。
- [ ] 间距均为 4px 基准值（4/8/12/16/24/32/48）。
- [ ] 字体族、字号阶梯符合第 3 节。
- [ ] 每个可交互组件实现了 hover / active / focus / disabled 四态。
- [ ] 聚焦环可见。
- [ ] 主按钮用 `accent`，危险操作用 `error`，语义正确。
- [ ] 响应式在 `<768 / 768–1024 / 1024–1280 / >1280` 均正常。
- [ ] 标题层级语义化，无跳级。
- [ ] 表单控件有 label，图标按钮有 aria-label。
- [ ] 与 `ui-preview.html` 的组件形态一致。

## 附：Agent 实现流程（推荐）

1. 读 `theme.md` 全文 → 明确约束。
2. 读 `tokens.json` → 生成 CSS 变量层。
3. 对照 `ui-preview.html` → 复用组件样式，不重复设计。
4. 按业务组装页面。
5. 逐项跑完第 10 节自检清单后交付。
